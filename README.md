# LCA PHP Exercises

## Project Title
LCA PHP Exercises — Foundational PHP scripts demonstrating core language capabilities.

## Description
This repository contains a collection of proof-of-concept PHP scripts built for the TechVibe junior developer onboarding programme. Each exercise covers syntax, variables, data types, built-in functions, and variable scope.

## Exercises

| Exercise | Folder | Topics Covered |
|----------|--------|----------------|
| Week 2, Exercise 01 | `week2_ex01_php_fundamentals/` | `echo`, `print`, `date()`, `rand()`, `intval()`, `gettype()`, variable scope (`global`, `local`, `static`), BMI calculator, type casting |
